# Let Me Out! – MAIN VI till MAIN VII: mottagningskvitto 2026-11-17

Status: kontrollerad ledarskapsmigrering och dokumentationsgranskning. Inget nytt spelbeslut, ingen ROM-auktorisation.

MAIN VII är nu efterträdande huvudroll och ansvarar för källkontroll, plan, designbeslutsberedning, arbetsordrar och grindar. ROM DEVELOPMENT III, GRAPHICS II, RESEARCH II, VERIFICATION II och ART/PACKAGING & MANUAL II har separata roller och mandaten utökas inte av migrationen.

Kontrollerat direkt: GitHub main HEAD 61bb44f39d6f6f3f2ceb8bfb4b134b7834e87db4 före detta kvitto; GitHub PR #7 open/draft/unmerged; Issue #8 open och ännu inte slutförd äldre oberoende kontroll; officiella Google Drive-projektmappen åtkomlig; ursprunglig 21-fils ZIP SHA256 och CRC verifierad och alla 57 beslutsrader läsbara.

Arbetsordning: först uttryckliga kvarvarande G5-beslut; vid bifall ny versionssatt acceptansbas, sedan endast separat uttrycklig G6-order och fysisk G0-preflight före ROM; oberoende VERIFICATION separat efter fryst leverans. Inget av detta påbörjas genom själva migrationen.
