# Kasserade rasterprov

Variant a är tidig M1/HMOVE med bred aktivering. Variant b lägger till skydd för spelarens aktiva grafik och befintliga P0-assistans. Variant c använder sen kompenserad HMOVE med bredare X-intervall än leveransen. Tar-filerna har den körda binären och dess källor. De tillhörande JSONL-filerna innehåller Gophers bildräkning och pixelobservationer.

`no-motion.jsonl`, `late.jsonl` och `calibrated.jsonl` är olika faktiska emulatorprov med RESP1 respektive tidigt kalibreringsskede av sen HMOVE. Dessa kopior loggade samma romfilnamn eftersom filen byggdes om mellan körningarna. Gophers svar och originalbilderna finns kvar. `base-fixture.jsonl` är den frysta start-ROM:ens resultat för samma crowd-koordinater.
